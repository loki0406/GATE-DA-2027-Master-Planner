# PDF ZIP downloads

Upload actual ZIP archives of PDFs here named `section-1.zip` through `section-7.zip` (lowercase). Section numbering matches the PPT folder.

The website automatically enables each download after the uploaded file is deployed and the visitor refreshes or returns to the browser window. No JavaScript edits are needed. A file that is not yet uploaded displays Coming soon; a failed availability check displays a temporary error.

Do not rename a PDF to .zip: create a ZIP archive containing the PDF files first.
